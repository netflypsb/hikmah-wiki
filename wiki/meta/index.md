## 🔍 How to Use This Federation

1. **Start with the Quran Wiki** for any Quranic query — it is the reference point for all other domains.
2. **Cross-reference via meta-wiki** when a question spans domains (e.g., "What does the Quran say about prayer, and how do the madhabs differ?").
3. **Future fiqh/hadith answers** will link back to quran-wiki/ for textual basis, never duplicating it.
4. **Add a new wiki** when a domain reaches 10+ sources that don't fit the Quran schema.
