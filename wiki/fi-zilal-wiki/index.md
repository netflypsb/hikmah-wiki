## Adding a New Surah

1. Place verbatim source at `raw/surah-NNN-[english-name].md`
2. Create curated page at `surahs/surah-NNN-[english-name].md`:
   - YAML frontmatter (surah_number, surah_name, revelation, verse_count, tags, sources)
   - Verse text (cross-reference quran-wiki)
   - Preserve original thematic section headings as `##` headers
   - Provenance markers `^[raw/...]`
   - Cross-link to quran-wiki counterpart
3. Update this index
4. Append to `log.md`
5. Local-only git commit
