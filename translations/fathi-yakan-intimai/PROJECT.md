## Translation Standards
- Quranic verses: Use Sahih International translation, cite as [Qur'an, Surah:Verse]
- Hadith: Cite with full collection reference (e.g., Sahih al-Bukhari, Book X, Hadith Y)
- Arabic terms: Include original Arabic in parentheses on first occurrence
- Style: Faithful to original meaning, natural English prose, preserve author's argumentative structure
